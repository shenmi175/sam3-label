# Model warmup example

`model_warmup.jpg` is copied unchanged from
`external/sam3/assets/images/test_image.jpg`. It is the multi-person,
full-body example used by the pinned upstream SAM3 examples and remains
subject to the notices and license shipped with `external/sam3`.

The web-auto model-load jobs use this image only for a real inference
warmup; inference results are not retained or returned to the browser.
